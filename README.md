# كفاءة (Kafa'a)

عرض تفاعلي من 8 شرائح لبرنامج «كفاءة» بمحورين: تأهيل العناصر (مع قائمة برامج تدريبية تختار منها الوزارة)، والدمج المجتمعي عبر مسار يؤهل طلاب جامعة حلب لمواقع الاحتكاك المباشر مع الناس، مع تساؤلات للوزارة بعد كل محور.

## محتوى الحزمة

```
index.html        الصفحة الرئيسية
css/style.css     التصميم
css/fonts.css     تعريف خط Alexandria
js/main.js        التنقل والحركة
fonts/            ملفات الخط (مضمّنة، لا تحتاج اتصالاً بالإنترنت)
```

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub وارفع إليه كل محتويات هذا المجلد كما هي.
2. من إعدادات المستودع: **Settings ← Pages**.
3. في **Source** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
4. بعد دقيقة تقريباً يظهر رابط العرض في نفس الصفحة.

ويمكن أيضاً فتح `index.html` مباشرة من الجهاز بدون إنترنت.

## النشر على Render

الحزمة تحتوي ملف `render.yaml` جاهزاً لنشر العرض كموقع ثابت (Static Site).

1. ارفع الملفات إلى مستودع على GitHub كما في الخطوة الأولى أعلاه.
2. من لوحة Render اختر **New ← Blueprint**، واربط المستودع.
3. سيقرأ Render ملف `render.yaml` تلقائياً وينشئ موقعاً باسم `kafaa` (يمكنك تغيير الاسم من الحقل `name` في الملف). اضغط **Apply**.
4. بعد انتهاء النشر يظهر رابط الموقع بصيغة `kafaa.onrender.com` (أو قريب منها).

لا يحتاج الموقع أي خطوة بناء، وكل تحديث ترفعه إلى المستودع يُنشر تلقائياً.

## طريقة العرض

- العرض يتنقل **شريحة شريحة** على كل الأجهزة.
- **اللابتوب:** عجلة الماوس أو أسهم لوحة المفاتيح. وفي بعض الشرائح يظهر عنصر جديد مع كل تمرير قبل الانتقال للشريحة التالية.
- **الموبايل والتابلت:** السحب للأعلى للتقدم، وللأسفل للرجوع.
- **شريحة البرامج المقترحة:** اضغط على أي برنامج لاختياره، ويظهر عدد الاختيارات أعلى الشريحة. على الموبايل تتنقل بين المستويات من الأزرار أعلى القائمة.
- زر **ملء الشاشة** في الأعلى مناسب للعرض أمام الجمهور.
- مفاتيح مفيدة: `Home` للبداية، `End` للنهاية.
