# بروتوكول الكرامة

عرض تفاعلي من 4 شرائح لفكرة شارات بروتوكول الكرامة: الشارات، مراحل الإعداد، دورة التقييم، والتوسع للقطاعات.

## محتوى الحزمة

```
index.html        الصفحة الرئيسية
css/style.css     التصميم
css/fonts.css     تعريف خط Alexandria
js/main.js        التنقل والحركة
fonts/            ملفات الخط (مضمّنة، لا تحتاج اتصالاً بالإنترنت)
```

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub وارفع إليه كل محتويات هذا المجلد كما هي.
2. من إعدادات المستودع: **Settings ← Pages**.
3. في **Source** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
4. بعد دقيقة تقريباً يظهر رابط العرض في نفس الصفحة.

ويمكن أيضاً فتح `index.html` مباشرة من الجهاز بدون إنترنت.

## طريقة العرض

- **اللابتوب والتابلت:** التنقل بعجلة الماوس، أو أسهم لوحة المفاتيح، أو السحب للأعلى والأسفل. في شريحة المراحل تظهر مرحلة واحدة مع كل تمرير.
- **الموبايل:** يتحول العرض إلى صفحة عادية تُقرأ بالتمرير، وتظهر المراحل تباعاً أثناء النزول.
- زر **ملء الشاشة** في الأعلى مناسب للعرض أمام الجمهور.
- مفاتيح مفيدة: `Home` للبداية، `End` للنهاية.
